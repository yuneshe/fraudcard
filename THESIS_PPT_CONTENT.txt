SLIDE 2: PROBLEM STATEMENT

- Need for real-time, adaptive fraud detection
- Challenge: Imbalanced datasets (fraud represents <1% of transactions)
- Requirement: High accuracy with minimal false positives

SLIDE 3: SOLUTION OVERVIEW
---------------------------
- Web-based fraud detection system using machine learning
- Real-time transaction analysis with risk scoring
- Multiple algorithm support for model comparison
- Interactive dashboard with visual analytics
- Scalable architecture with separate ML service

SLIDE 4: SYSTEM ARCHITECTURE
----------------------------
- Laravel Backend (PHP) - Web framework and business logic
- Python ML Service (Flask) - Fraud prediction engine
- MySQL Database - Transaction storage and management
- Chart.js - Data visualization
- RESTful API integration between components

SLIDE 5: METHODOLOGY
--------------------
Dataset: Kaggle Credit Card Fraud Dataset (284,807 transactions)
Features: 30 PCA-transformed features (Time, V1-V28, Amount)
Algorithms: Random Forest, Logistic Regression, SVM, Decision Tree
Training: 80/20 train-test split with cross-validation
Evaluation: Accuracy, Precision, Recall, F1-Score
