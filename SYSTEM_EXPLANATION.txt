FRAUD DETECTION SYSTEM - SYSTEM OVERVIEW
========================================

SYSTEM ARCHITECTURE
-------------------
Components:
- Laravel Backend (http://localhost:8000) - PHP framework handling web requests and business logic
- Python ML Service (http://127.0.0.1:5000) - Flask API with scikit-learn fraud detection model
- MySQL Database - Stores users, transactions, and fraud reports
- Blade Frontend - Laravel views for dashboard, transactions, alerts, reports, and prediction

DATABASE SCHEMA
---------------
users table:
- id, name, email, password, role (admin/analyst), timestamps
- Authentication handled via Laravel Sanctum (disabled in demo mode)

transactions table:
- id, transaction_id (unique), Amount, Time, merchant
- risk_score (float), fraud_status (boolean)
- V1-V28 (PCA-transformed features from Kaggle dataset)
- Indexed on transaction_id, fraud_status, risk_score, transaction_time

fraud_reports table:
- id, transaction_id (foreign key), risk_score (float)
- prediction (string: 'fraud'/'legitimate'), confidence (float)
- Linked to transactions via foreign key with cascade delete

FRAUD DETECTION FLOW
--------------------
1. User enters transaction details in prediction form at /predict
2. Laravel validates input (Amount, Time, merchant)
3. Laravel generates random V1-V28 features (for demo)
4. Laravel sends POST request to Python ML service at http://127.0.0.1:5000/predict
5. Python service loads selected ML model (RandomForest, LogisticRegression, SVM, or DecisionTree)
6. Features are scaled using StandardScaler
7. Model processes features and returns prediction
8. Result displayed in Laravel frontend with risk indicators

ML MODEL DETAILS
---------------
Algorithms: Multiple models supported
- RandomForest Classifier (default)
- Logistic Regression
- Support Vector Machine (SVM)
- Decision Tree

Training Data: Kaggle Credit Card Fraud Dataset (284,807 transactions, 0.17% fraud rate)
Features:
- Time: Seconds elapsed since first transaction
- V1-V28: PCA-transformed features (anonymized transaction characteristics)
- Amount: Transaction amount in dollars
- merchant: Merchant category (string)

Model Parameters (RandomForest):
- n_estimators: 50 (reduced for memory efficiency)
- max_depth: 10
- min_samples_split: 5
- class_weight: balanced
- n_jobs: 1 (single thread for memory efficiency)

Model Files:
- fraud_model_randomforest.pkl
- fraud_model_logisticregression.pkl
- fraud_model_svm.pkl
- fraud_model_decisiontree.pkl
- scaler.pkl
- feature_names.pkl

Outputs:
- fraud: 0 (legitimate) or 1 (fraudulent)
- prediction: 'fraud' or 'legitimate'
- risk_score: Probability of fraud (0.0 to 1.0)
- confidence: Maximum probability (0.0 to 1.0)
- probabilities: {legitimate: float, fraud: float}

- High risk transactions (risk score > 0.7)

Reports (/reports):
- Summary statistics table

- Export to CSV functionality

Prediction (/predict):
- Form to input transaction details (Amount, Time, merchant)

- Display prediction results with risk indicators

Analysis (/analysis):
- Statistical analysis from ML service
- Fraud distribution doughnut chart
- Feature correlations bar chart
- Merchant category analysis dual-axis bar chart

STARTUP INSTRUCTIONS
--------------------
1. Start MySQL database
2. Start Laravel backend: php artisan serve (from backend directory)
3. Start Python ML service: python app.py (from ml-service directory)
4. Access application at http://localhost:8000
